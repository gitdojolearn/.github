# GitDojo

### Learn Git by doing.

Practice real Git commands in a safe, visual browser workspace.

[**Try GitDojo**](https://git-dojo-drab.vercel.app) ·
[**Explore the project**](https://github.com/gitdojolearn/GitDojo) ·
[**Contribute**](https://github.com/gitdojolearn/GitDojo/blob/main/CONTRIBUTING.md)

---

GitDojo makes Git easier to understand by letting you work through what Git changes as you type. Each lesson runs in an isolated browser repository, with a terminal, code editor, and visual repository graph.

## Learn by doing

- **Lessons** — Build Git skills with guided exercises and progressive hints.
- **Practice** — Try short, focused tasks without step-by-step instructions.
- **Challenges** — Solve realistic Git problems independently.
- **Playground** — Experiment in a persistent sandbox.
- **Visual feedback** — Watch files, staging, branches, and commits change as you work.

GitDojo checks the resulting repository state, so different valid Git commands can reach the same objective. There is no real shell and no connection to real repositories.
